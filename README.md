# Хочу в онлайн — Krylova School

Сайт-візитка онлайн-курсу **«Хочу в онлайн»** Поліни Крилової: як експерту запустити свій онлайн-курс.

## Що тут є

- `index.html` — увесь сайт в одному файлі (логотип вбудований усередину).
- `logo.jpg` — оригінал логотипа.

## Як відкрити

Двічі клацнути на `index.html` — сайт відкриється в браузері.

## Примітки

- Відгуки, програма курсу й контакти на сайті — поки що приклади.
- Кнопка «Зробити передоплату» — муляж, онлайн-оплату підключимо пізніше.
